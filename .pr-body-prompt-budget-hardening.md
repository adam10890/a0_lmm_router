# Local Fleet Prompt Budget Hardening

## Summary

This PR hardens Agent Zero's Local Fleet path for long-context llama.cpp
Router Mode chats:

- filters rendered MCP prompts by agent profile
- keeps heavyweight MCP surfaces available to specialist profiles
- enforces conservative Local Fleet output token caps
- records context/tool/MCP/output telemetry for live diagnosis

## Why

The native A0 tool exposure filter reduced the main tool prompt substantially,
but live Local Fleet chats still carried large MCP prompts and could over-generate
thousands of local tokens. That left Gemma/Qwen local slots with less useful
conversation budget and occasional repeated-chunk failures.

## Implementation

- `helpers/mcp_exposure.py` parses the rendered A0 MCP prompt into server/tool
  sections and applies profile allowlists from `mcp_exposure`.
- `_12_mcp_prompt.build_prompt/end` hooks replace the MCP prompt only when the
  Local Fleet preset is active, with an `always` mode available for testing.
- `helpers/output_budget.py` injects or caps `max_tokens`/`max_completion_tokens`
  for Local Fleet model calls only.
- Existing chat/utility `tool_call_adapter` hooks now pass the role so chat and
  utility calls can use different output budgets.
- The context guard stores telemetry even when no compression is required and
  includes MCP savings in compression logs.

## Defaults

- `agent0` MCP exposure keeps only `lmm_router.fleet_status` and
  `lmm_router.list_slots`.
- `developer`/`researcher` profiles retain development and research MCP tools.
- chat output default: `2048`, hard cap: `4096`.
- utility output default: `768`, hard cap: `1024`.

## Operator Notes

After deploying, restart Agent Zero so function hooks reload. A successful Local
Fleet chat should show `LMM Router MCP exposure` and, when caps are injected,
`LMM Router output budget` in the chat log. Manifest snapshots are written to
`data/tool_exposure_manifest.json` and `data/mcp_exposure_manifest.json`.
